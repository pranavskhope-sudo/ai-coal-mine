# CoalSight AI — SIH Prototype Frontend

A polished, self-contained React/Vite prototype for the CMPDI/CIL reporting problem.

## Run
npm install
npm run dev

## Build
npm run build

## Features
- Dashboard with production, quality and methane analytics
- CSV upload and demo dataset
- AI-assisted structured report generation (prototype/local workflow)
- Report download and Print/Save as PDF
- Geological insights
- Safety monitoring screen
- Responsive UI

This version intentionally works without a separate Render backend so the core SIH demo flow does not break when an external API is asleep or unavailable.
